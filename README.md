# Projet IOT - Smart Energy

Ce projet consiste en une solution de surveillance de l'énergie intelligente utilisant un ESP32, Node-RED et un dashboard personnalisé.

## Structure du Projet

- `simulateur/` : Simulateur Python de l'ESP32 via MQTT.
- `nodered/`    : Flux Node-RED pour la gestion des données.
- `dashboard/`  : Interface utilisateur web.
